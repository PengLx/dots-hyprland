# Gmail 通知偏好

> 这个文件由 AI triage 助手读取,用来判断每封邮件是否值得弹桌面通知。
> 用自然语言写,想到什么写什么 —— AI 会理解上下文,不需要语法。
> 改完即时生效(每次有新邮件来时重新读)。

## ✅ 我希望收到通知

- **验证码 / OTP / 一次性密码**
  - 把数字提取出来放进 `code_to_copy`(关键),通知本身要醒目
  - 来源: 银行、Stripe、PayPal、Google、GitHub、Apple、各种 SaaS 登录验证、taobao/支付宝/微信支付
- **银行 / 支付重要事件**
  - 大额转账(> ¥1000)成功 / 失败
  - 卡被冻结 / 异常登录
- **包裹 / 物流取件码**(顺丰、菜鸟、SF Express、DHL 等)
  - 提取取件码
- **工作上紧急的邮件**
  - 来自我的 boss / team 的、@ 我的、subject 含「URGENT / 紧急 / ASAP」

## ❌ 不要打扰我

- 商业广告 / 营销邮件 / 促销
- 邮件订阅(newsletter)
- GitHub issue / PR 通知(我自己定期看)
- LinkedIn / 社交平台邀请
- 平台例行报告 / 月度账单(除非金额异常)

## 📝 通知格式建议

- title 用中文 + 简洁
- body 包含关键信息(发件人 + 关键内容)
- 验证码场景:title 直接是「<服务> 验证码」,body 是码 + 发件人
- 物流场景:title 是「快递取件码」,body 是码 + 包裹号简写

## 📌 特殊说明

- 拿不准时 → 倾向**不**打扰我(我会自己看 sidebar)
- 完全相同的码连续出现两次以内不要重复通知(由 watcher 去重,你不用管)
